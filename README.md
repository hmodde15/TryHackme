Exercices finaux TryHackMe : https://tryhackme.com

Ce dépôt regroupe mes notes et mes réponses pour les exercices finaux de la certification SAL1 (SOC Analyst Level 1) de TryHackMe.

Objectif

Garder une trace de ma démarche d'analyse et m'en servir pour réviser. L'idée est de documenter la méthodologie plus que les réponses : triage de l'alerte, investigation, puis escalade.

Organisation

Chaque exercice est noté de la même façon :

Contexte : le scénario et l'alerte de départ
Investigation : les étapes suivies et les outils utilisés
Réponses : ce qui a été trouvé et les conclusions
